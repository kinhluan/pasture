Personas for `pasture doc review`. Each file is handed, verbatim, to a fresh headless
agent as its whole brief — keep them self-contained. Add one here and pass its name
with `--personas`.

The roles are inspired by the Elephant-Goldfish Model (https://egm.dev,
github.com/google/elephant-goldfish-model, Apache-2.0); the text here is our own.
